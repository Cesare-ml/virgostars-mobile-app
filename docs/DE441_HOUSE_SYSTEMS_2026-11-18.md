# Experimental DE441 chart and house systems — 18 November 2026

The explicit **Calculate experimental DE441 chart** action now combines the existing Rust position pipeline with the existing `astrological-functions/astro-com-house-provider` dispatcher. It adds no new astronomical or house-system algorithm. The renderer offers each successfully calculated 12-cusp method as a separate house system; all 24 selector IDs are shown with per-method success/failure. `GAUQUELIN_36` is displayed separately as 36 clockwise sector boundaries and is never cast to 12 houses. Unavailable/polar/non-convergent methods retain their error and are not replaced by another system. Pullen SD can return repeated cusps, so an ordinary house-position locator may explicitly leave a placement unavailable.

Sunshine obtains a real geocentric apparent solar declination in the true equator of date from the Rust DE441 reader. The other required ARMC, ASC, MC, true obliquity and vertex come from existing Rust `house_angles`. The request supplies explicit UTC and coordinates; **UT1 is approximated as UTC**, without measured Earth-orientation parameters. The core's approximate UTC→TDB conversion bounds this app path to 1972-01-01 through 2027-06-27. House axes and equatorial body coordinates use IAU 2006/2000B; ecliptic positions use the existing experimental Vondrák/77-term path with emission refinement. These different frame/model choices are intentional and remain subject to numerical review. Mars–Pluto entries are system barycenters, not individual planet centers; nodes, apsides and Chiron are explicitly unavailable.

Within that modern UTC window the core package is verified for length/SHA-256; the equatorial and Sunshine paths use a single core file only after requiring the epoch to be more than a day inside its logical interval. The experimental ecliptic path uses the per-request multipack provider. Hash verification and opening are separate operations, so concurrent replacement is an outstanding hardening issue. No fallback, network download or DE441 data bundling is added.
