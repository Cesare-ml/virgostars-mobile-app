# DE441 release source for future Mobile downloads — 2026-11-18

The owner published [de441-mobile-v1.0.0](https://github.com/Cesare-ml/VirgoStars-Ephemeris/releases/tag/de441-mobile-v1.0.0) as a GitHub **pre-release**. `src/assets/de441-release-source-v1.json` records the explicit versioned release and asset prefix, plus the v1 manifest's expected length and SHA-256. Combining this fixed prefix with a filename already in the ten-entry local catalog identifies the intended release asset. The manifest itself is a separate asset; no `.eph` file is bundled in this repository.

On 2026-11-18 the GitHub release metadata reported all ten pack filenames, lengths and `sha256:` digests matching the existing Mobile catalog and the separately verified local manifest. The published manifest reported 8,657 bytes and SHA-256 `a4a204169555ee4ec01d5b3f25ce331a44ff6c9fd273d7f812cfa245e6ef6b7a`. This is a metadata comparison; no asset was downloaded in this check. A release tag or GitHub metadata is not a signed catalog or proof that hosting rights have been reviewed. `distributionRights` remains `review_pending`.

**Not implemented:** no downloader, download button, background networking, remote URL IPC, automatic installation or chart-engine activation is added by this metadata. Existing local user-selected imports still verify expected length and SHA-256 before atomic installation. A future downloader must use an allowlisted release/pack mapping, bounded streaming, progress and cancellation, explicit error handling, hash and length verification before installation, safe redirects, available-space handling and Android offline/interruption tests. It must retain the separate distribution-rights review and never silently change astronomy models.
