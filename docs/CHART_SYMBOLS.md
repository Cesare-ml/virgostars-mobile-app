# Chart symbols — private local prototype

The app stages zodiac and celestial-body glyphs directly from the sibling `astrological-assets` checkout for local builds. `scripts/prepare-private-glyphs.mjs` selects only the paths required by the wheel, latitude view and mobile lists, checks each against the source pack's exact SHA-256 and private permission metadata, and writes 104 output files under the ignored `.local/private-glyphs/` directory. `npm run verify:chart-symbols` checks the built copies against the staged manifest. The app does not commit the upstream artwork into this repository.

The source pack is approved for **private use**, not public redistribution. An APK containing those glyphs must not be publicly distributed until the rights holders and underlying font rights have been reviewed and the upstream public-release checks pass. The owner has selected CC BY 4.0 for their own contributions; this does not establish the rights for underlying third-party artwork or fonts. See `../astrological-assets/docs/RIGHTS_AND_REVIEW.md` and `../astrological-assets/docs/FONT_RIGHTS_RESEARCH.md`.

The white source glyphs are tinted in the light presentation. Individual planet and zodiac images carry localized accessible names even where the visual display uses only a glyph. The upstream pack has no retrograde variants for several points: aliases use the base glyph, and the two missing mean-apogee and mean-perigee variants add a small `R` to the source image. Remaining house numbers use locally generated open-font symbols. Non-glyph renderer artwork still uses synthetic placeholders, so this is not full desktop visual parity.

The mobile host compensates for the shared renderer's CSS-pixel resize by setting the WebGL drawing buffer to 1.5 times device density, up to a ratio of 4 and a 3072-pixel side. Zoom extends to 300%, with density reduced at larger sizes to respect the cap. It updates on zoom, window resize and context restoration. The host clears the renderer's scene background and hides its monochrome aspects backdrop so the parent background shows through. The adapter uses internal renderer fields and a narrowly matched backdrop; recheck compatibility when updating the shared package.

On 2026-11-18 an Android debug build on a Pixel 8 Pro rendered a 1363-pixel drawing buffer for a 404 CSS-pixel canvas and 3072 pixels at 300% zoom. A later local build loaded the private glyphs, displayed wheel and compact time controls together, advanced a day without hiding the canvas, and changed the live indicator on pause/resume. The available body and sign images loaded in the planets panel. These are functional checks on one device, not low-memory, full lifecycle or scientific-accuracy assessments.
