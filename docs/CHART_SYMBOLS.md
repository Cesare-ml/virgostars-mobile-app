# Chart symbols — local prototype

The mobile host provides 70 transparent, locally generated PNG textures for zodiac signs, house numbers, the calculated bodies and their retrograde variants. They are typeset from Noto Sans Symbols and Noto Sans Symbols 2 (The Noto Project Authors), licensed under the SIL Open Font License 1.1. Original font files and license texts are in `third_party/noto-symbols/`; the license texts are also packaged in `assets/licenses/` and a credit appears in Settings. The font sources are the Google Fonts `ofl/notosanssymbols` and `ofl/notosanssymbols2` repositories. Source SHA-256 values are pinned in `scripts/generate-chart-glyphs.py`.

The images are a separate typographic treatment, not a reproduction of VirgoStars proprietary artwork. Node and apogee variants use small `M`, `T` or `O` markers for mean, true and osculating; perigees use `P` with the variant marker; retrograde variants add `R`. Other optional renderer textures remain synthetic placeholders. The default wheel uses the shared renderer's monochrome dark skin; the complete design and contrast require further review on physical devices.

For reproduction, install Pillow in an appropriate Python environment and run `python scripts/generate-chart-glyphs.py <new-output-directory>`. The script validates font checksums and glyph availability and refuses to overwrite an existing destination. Existing generated PNGs are tracked under `src/chart-symbols`. The build layers these over manifest-verified synthetic assets; `npm run verify:chart-symbols` checks all 70 build outputs and both license files. No private assets or fonts are copied into the build.
## Android emulator checkpoint — 2026-11-16

The x86_64 Android 36.1 emulator was used with the local Swiss/Moshier build and a fictional Rome chart. The rendered wheel showed the Noto zodiac and body glyphs in the monochrome dark skin in place of the main checkerboard symbols. Switching to Placidus and a simulated WebGL loss/restoration completed without a chart error. The glyph size and contrast were inspected in an emulator screenshot; this is not a physical-device accessibility or visual-parity review. Some optional textures still originate from synthetic placeholders.
